# 광고 브리프 작성 (2부)

광고주가 답한 1부 질문지(0~11번)를 받아 내부용 브리프(2부)를 만든다. 브리프는 광고주가 채우지도 보지도 않는 내부 문서다. AI가 초안을 쓰고 사람이 확정한다.

## 입력
- 1부 답변 (상호·담당자·연락처, 제품/서비스, 타깃, 목적, 고민, 경쟁사, 강점, 필수·금지 표현, 레퍼런스, 제품 유무, 사진·로고, 매체)
- 동의 기록 (개인정보 필수 동의, 포트폴리오 선택 동의, AI 사용 고지)
- 필수 동의가 없으면 작성하지 말고 중단한다.

## 절대 규칙
1. 1부에 없는 사실(후기, 숫자, 수상 이력)을 쓰지 않는다. 근거가 없으면 "근거 없음"이라고 적는다.
2. 답이 "모르겠음"이거나 AI가 추정해서 채운 내용에는 반드시 "추정"을 표시한다.
3. 모든 항목 끝에 출처 태그를 붙인다: `[1부 답 n번]` / `[AI 초안]` / `[사용자 결정]` / `[추정]`.
4. `[사용자 결정]` 항목은 후보만 제시하고 하나로 확정하지 않는다.
5. 경쟁사가 로그인해야 보이는 곳(인스타그램 등)이면 내용을 읽었다고 하지 말고 캡처를 요청한다.

## 작성할 항목 (영역 / 항목 / 태그)
**문제 정의**
- 광고주·제품: 이름과 한 줄 설명 [1부 답 0, 1]
- 산출물 유형: 배너(1차). 숏폼·랜딩은 추후 [사용자 결정]
- 제품 유무: 제품형 / 무형(서비스·가게·병원·금융 등) [1부 답 9]
- 심의 대상 여부: 대상 / 비대상 / 확인 필요. 의료, 건강기능식품, 금융 등은 대상 [AI 초안]
- 배경: 현재 상황 2~3줄 [AI 초안, 1부 4번 기반]
- 풀어야 할 문제: "~ 때문에 ~가 안 된다" 한 문장 [AI 초안]
- 광고 목적·핵심 KPI: 목적 하나와 목표 숫자. 목표가 없으면 "확인 필요". 목적이 4종(매출 / 문의·상담 / 회원가입 / 방문·인지) 중 애매하면 가장 가까운 것에 넣고 KPI 칸에 구체적으로 적는다. 단골 재방문처럼 대상만 다른 경우는 목적이 아니라 타깃으로 처리한다. "모르겠음"이면 1부 1~2번으로 추정해 "추정"을 표시한다 [1부 답 3]

**타깃**
- 타깃: 나이·상황·관심사로 한 줄. "모두"는 금지 [AI 초안, 1부 2번]
- 소비자 인사이트: "사람들은 ~하지만 실제로는 ~하다" 한 문장 후보 3개 [사용자 결정]

**메시지**
- 경쟁·대안: 소비자가 대신 고를 수 있는 것 [1부 답 5]
- 핵심 혜택: 경쟁사가 말하기 어려운 것 하나 [AI 초안, 1부 6번]
- 근거: 광고주 자료의 수치·후기·수상만. 없으면 "근거 없음" [1부 답 6]
- 핵심 메시지: 소비자에게 딱 한 가지만 말한다면, 후보 제시 [사용자 결정]
- 원하는 행동(CTA): 예) 자세히 보기, 상담 신청, 구매하기, 후보 제시 [사용자 결정]

**아이디어·비주얼** (아이디어 방향 3개는 ad-ideation 단계에서 채움)
- 톤·비주얼 방향: 말투·분위기·색·구도. 1부 8번 레퍼런스가 있으면 우선 [AI 초안]
- 이미지 사용 방침: ad-image-router 스킬로 결정, 광고주 확인 필요 [사용자 결정]

**제작 조건**
- 필수·금지 표현 [1부 답 7], 제작 자료 [1부 답 10], 매체·규격·집행 기간(없으면 미정) [1부 답 11]
- 납품 형태: 매체별 파일 형식·용량 [사용자 결정]
- 시안 개수: 기본 2종(같은 아이디어에서 메시지·버튼 문구·버튼 색만 다른 변형) [사용자 결정]
- 수정 범위: 포함 횟수 ○회 [사용자 결정]
- 테스트 아이디어: 최소 3종, 메시지와 비주얼 콘셉트 한 쌍

## 출력
- `02_brief.md`에 위 항목을 표로 저장한다 (영역 | 항목 | 내용 | 태그).
- 마지막에 "사람이 확정할 항목" 체크리스트를 붙인다: 모든 `[사용자 결정]`, 모든 `[추정]`, 심의 확인 필요, 근거 없음.
- 사람이 확정하기 전에는 다음 단계(아이디어, 이미지)로 넘어가지 않는다.
