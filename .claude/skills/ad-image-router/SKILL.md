# 배너 이미지 방침 라우터

확정된 브리프와 선택된 아이디어를 받아 이미지를 어떻게 만들지 결정한다. 결과는 이미지 방침, 생성 프롬프트, 검수 기준이다.

## 1단계: 경로 결정 (제품 유무)

| 상황 | 방침 |
|---|---|
| 제품형, 사진 있음 | 원본 사진에서 제품을 오려(누끼) 그대로 쓰고, 배경·그림자·소품만 AI로 생성. 가장 안전한 기본 경로 |
| 제품형, 원본 기반 재생성 | 원본을 참조 이미지로 넣어 AI가 다시 생성. 포장 글자·로고·무늬·색이 바뀌기 쉬우므로 원본과 나란히 비교 검수 필수. 다르면 쓰지 않음 |
| 제품형, 사진 없음 | 광고주에게 사진 요청. AI로 제품을 새로 그리지 않음 (실제와 다르면 허위 광고 위험) |
| 무형 (서비스·가게·금융 등) | 공간·사람·상황·상징 이미지를 AI로 생성하거나 실제 매장 사진 사용 |
| 무형 (병원) | 내부는 실제 사진 권장. 시술 장면, 전후 비교처럼 보이는 AI 이미지는 쓰지 않음 |

선택한 경로와 이유를 `04_images/policy.md`에 기록하고, 광고주 확인이 필요한 항목은 표시한다.

## 2단계: 심의 업종 분기
의료, 건강기능식품, 금융 등 광고 심의 대상이면 일반 흐름에 두 단계를 더한다. 업종별 규정은 시작 전에 확인이 필요하다.
1. 아이디어 확정 후 카피 사전 점검: AI가 위험 표현을 1차로 거르고 사람이 확인
2. 시안 제작 (변형 2종)
3. 광고주가 시안 선택, 수정 요청
4. 선택한 시안의 완성본 심의: 카피뿐 아니라 이미지까지 포함한 광고물 전체가 대상일 수 있음 (평균 1~2주 예상, 추정)
5. 납품

## 3단계: 프롬프트 작성 규칙
- 모든 프롬프트에 "글자, 간판, 로고, 워터마크 넣지 말 것"을 고정으로 넣는다.
- 한글 카피와 로고는 AI로 만들지 않는다. 합성 단계(ad-compose)에서 원본 로고 파일과 텍스트를 얹는다.
- 문구와 버튼을 얹을 빈 공간(보통 상단 또는 하단)을 구도에 확보하도록 지시한다.
- 아이디어 3안은 서로 겹치지 않게 별도 프롬프트로 만든다.
- 브리프의 톤·비주얼 방향과 1부 8번 레퍼런스를 반영한다.

## 4단계: 저장과 기록
- 마음에 드는 결과는 즉시 저장한다. 같은 결과를 다시 만들기 어렵다.
- 생성한 모든 이미지와 프롬프트, 사용 도구, 날짜를 `04_images/`에 로그로 남긴다.
- 이미지 도구가 상업 이용을 허용하는지 확인하고 기록한다.

## 검수 기준 (ad-qa에 전달)
- 제품형: 원본과 나란히 놓고 포장 글자·로고·무늬·색을 비교한다. 다르면 폐기.
- 이미지 안에 글자·로고가 생성되어 있지 않은지 확인한다.
- 병원·금융 등에서 오인될 수 있는 장면(시술, 전후 비교, 보장 오인)이 없는지 확인한다.
- 사람이 최종 승인하기 전에는 납품 단계로 넘기지 않는다.
